# ProjectEuler
My solutions to [Project Euler](https://projecteuler.net/about)!

I really like Julia for its usage as a high-level mathematically inclined
language, so a lot of the solutions have been written with that. I also 
sometimes like to use Project Euler as a starting point to learn new languages, 
so there are a few (sporadic) solutions written in Fortran and APL as well.
Ironically, despite Python being my main language for everyday use, I don't
really find any desire to write solutions with it, because I already feel
confident enough in my knowledge of it.
