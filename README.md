# ProjectEuler
My solutions to [Project Euler](https://projecteuler.net/about)!

I really like Julia for its usage as a high-level mathematically inclined
language, so a lot of the solutions have been written with that. I also 
sometimes like to use Project Euler as a starting point to learn new languages, 
so there are a few (sporadic) solutions written in Fortran, C, and APL as well.
Ironically, despite Python/Numpy being my main language for everyday use, I don't
really find any desire to write solutions with it, because I already feel
confident enough in my knowledge of it.

Note: I do not claim full authorship over all solutions. Usually what I'll do
is try to solve the problem myself first. Then, once I have the answer, I'll look
at the guide on ProjectEuler (if there is one) and/or the forums to see what others
have done, to try to improve the efficiency.
